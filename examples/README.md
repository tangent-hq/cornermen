# Example: one week with the team

A filled-in snapshot of the workspace after about a month, for a **fictional** user, Alex: a product designer who wants to train consistently, ship a small side project, and stop forgetting friends' birthdays.

Read these to see what the agents actually write:

- `shared/priorities.md`: what the coordinator decided for the week
- `coordinator/inbox.md`: agents talking to each other through the team board
- `coordinator/plans/2026-03-14.md`: the Saturday plan Alex approved
- `*/summary.md`: what each agent tells the others (note what Social leaves out)
