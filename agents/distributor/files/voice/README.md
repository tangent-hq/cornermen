# Voice

`samples/` holds writing the user **explicitly adds** for this purpose: published posts, essays, pieces they wrote and are happy to share, plus a few pieces by others they'd like to sound like. Never copy in chats, voice notes or private messages, even ones you can see. Distributor turns the samples into `guide.md`: traits, phrases to avoid, and rules per format (README, X, LinkedIn, long form). Every public draft is checked against it; the user's edits on drafts become new rules.
